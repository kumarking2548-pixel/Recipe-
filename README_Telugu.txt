ULTIMATE GADGETS — ఫోన్‌లో వెబ్‌సైట్ సెటప్

ఫైళ్లలో:
1. index.html — హోమ్ పేజీ, ప్రొడక్ట్స్, కార్ట్, చెకౌట్
2. style.css — డిజైన్
3. script.js — ప్రొడక్ట్స్, కార్ట్, WhatsApp ఆర్డర్
4. policies.html — షిప్పింగ్/పేమెంట్/రిటర్న్ పాలసీలు

ముఖ్యమైనవి — పబ్లిష్ చేయడానికి ముందు:
A) script.js తెరిచి STORE_WHATSAPP = "919999999999" లో 919999999999 స్థానంలో నీ WhatsApp Business నంబర్ పెట్టు. ఉదా: 91 + 10 అంకెల నంబర్. + లేదా ఖాళీలు వద్దు.
B) products జాబితాలో ఉన్న sample ధరలు/ఫోటోలు/వివరాలు నిజమైన supplier ధరలు కావు. Supplierతో stock, wholesale ధర, GST invoice, warranty, returns, dispatch time నిర్ధారించిన తర్వాతే మార్చి publish చేయి.
C) policies.html లో hello@example.com స్థానంలో నీ business email పెట్టు.
D) UPI/COD ఇంకా payment gatewayతో ఆటోమేటిక్‌గా కనెక్ట్ కాలేదు. Checkout WhatsAppలో order request పంపుతుంది. నువ్వు stock, delivery, final price confirm చేసిన తర్వాత మాత్రమే payment తీసుకో.
E) Dropshipping supplierతో customer address పంచుకునే ముందు వారి privacy/data handling పద్ధతి తెలుసుకో; customer consent తీసుకో.

ఫోన్‌లో Publish చేయడం (GitHub Pages):
1. Chromeలో https://github.com తెరిచి account create/login చేయి.
2. + → New repository నొక్కు.
3. Repository name: ultimate-gadgets-store
4. Public ఎంచుకుని Create repository నొక్కు.
5. Add file → Upload files నొక్కు.
6. ZIPని కాదు — ZIPలోని నాలుగు ఫైళ్లను extract చేసి ఒక్కొక్కటిగా upload చేయి.
7. Commit changes నొక్కు.
8. Repository Settings → Pages తెరువు.
9. Build and deploymentలో Deploy from a branch ఎంచుకో.
10. Branch: main; folder: /(root); Save.
11. కొద్ది నిమిషాల తర్వాత Settings → Pagesలో నీ website link కనిపిస్తుంది.

గమనిక:
- GitHub Pages static website hosting మాత్రమే. ఇది order fulfilment, inventory, live payment, courier booking లేదా COD verification ఆటోమేటిక్‌గా చేయదు.
- India అంతటా delivery అని చూపడం మాత్రమే సరిపోదు. ప్రతి PIN codeకు supplier/courier service ఉందో నిర్ధారించాలి.
- UPI/COD payment gateway, automated order dashboard, tracking కావాలంటే తరువాత e-commerce platform/paid integration అవసరం.
